# תוכנית: פרסום בגוגל פליי, תשלומים, התחברות ושמירת נתונים, דירוג עולמי/ארצי

## 1. פרסום בגוגל פליי (חנות האפליקציות)

האפליקציה היא אפליקציית ווב (PWA). כדי להופיע ב-Google Play יש שני מסלולים:

- **TWA (Trusted Web Activity)** — מומלץ לאפליקציה שלנו: עוטפים את האתר המפורסם כאפליקציית אנדרויד באמצעות Bubblewrap. דורש: פרסום האתר, קובץ `assetlinks.json` לאימות בעלות על הדומיין, אייקונים ומסכי פתיחה. חשבון מפתח גוגל עולה 25$ חד-פעמי.
- **Capacitor** — עטיפה נייטיבית מלאה (מאפשרת גם iOS בעתיד). יותר גמיש אבל דורש בנייה ב-Android Studio.

**בתוכנית:** הכנת הפרויקט ל-TWA — מניפסט PWA מלא, אייקונים (512/192), מסך פתיחה, `assetlinks.json`, והוראות שלב-אחר-שלב להעלאה ל-Play Console. (ההעלאה עצמה נעשית מחשבון הגוגל שלך — אני מכין את כל הקבצים.)

## 2. תשלומים — הכי קל ובטוח עם עמלות נמוכות

אילוץ חשוב: **אפליקציה שמופצת ב-Google Play ומוכרת מוצרים דיגיטליים (מטבעות, פרימיום) חייבת לפי מדיניות גוגל להשתמש ב-Google Play Billing** — עמלה של 15% (עד מיליון $ בשנה). שימוש בתשלום חיצוני (Stripe/Paddle בעמלה ~3%) בתוך אפליקציית Play עלול לגרום להסרת האפליקציה.

לכן שני מסלולים:

- **מסלול א׳ — ווב + PWA בלבד (ללא Play):** תשלומים דרך Stripe/Paddle של Lovable — עמלה נמוכה (~3%), הכי קל ומהיר. משתמשים מתקינים את האפליקציה מהדפדפן ("הוסף למסך הבית").
- **מסלול ב׳ — גם ב-Google Play:** רכישות בתוך האפליקציה דרך Play Billing (15%), ואתר נפרד לרכישות ווב.

**בתוכנית (מסלול א׳ כברירת מחדל):** הפעלת תשלומי Lovable (Stripe), חיבור לחנות הקיימת: מוצרי "כסף" (תיבות, רמזים, גלגל מזל, פרימיום חודשי/שנתי) יהפכו מכפתורי "🚧 בקרוב" לרכישות אמיתיות, עם webhook שמזכה את השחקן אוטומטית. אם תבחר מסלול ב׳ — נתכנן שלב נוסף ל-Play Billing.

## 3. התחברות (אימייל / גוגל) ושמירת נתונים בענן

כיום כל ההתקדמות נשמרת ב-localStorage במכשיר בלבד — החלפת מכשיר = אובדן נתונים.

**בתוכנית:** הפעלת Lovable Cloud (מסד נתונים + התחברות מובנים):
- התחברות עם **גוגל** (כפתור אחד) ועם **אימייל** (קישור קסם / סיסמה).
- **כניסת אורח נשמרת**: מי שלוחץ "התחל לשחק" משחק מיד, ויכול לקשר חשבון מאוחר יותר מהגדרות — ההתקדמות מתמזגת לחשבון.
- טבלאות בענן: פרופיל שחקן (מטבעות, רמזים, שלב, מדבקות, כרטיסים, רצף, בוסטים), עם סנכרון אוטומטי — נכנסים ממכשיר אחר והכל שם.
- אבטחה: RLS — כל שחקן רואה וכותב רק את הנתונים שלו.

## 4. דירוג עולמי וארצי — כן, ולא קשה

אחרי שיש ענן (סעיף 3), דירוג זה פשוט יחסית:
- טבלת דירוג עם ניקוד (נגזר משלב, דיוק, רצף ונקודות משחקים).
- **דירוג עולמי** + **דירוג ארצי** (לפי ארץ שנבחרת בהגדרות / מזוהה אוטומטית).
- מסך "דירוג" חדש: טופ 100, המיקום שלך מודגש, עדכון חי.
- סינון תקופות: שבועי / חודשי / כל הזמנים.

## סדר עבודה מוצע

1. הפעלת Lovable Cloud + התחברות גוגל/אימייל + סנכרון פרופיל (הבסיס לכל השאר).
2. מסך דירוג עולמי/ארצי.
3. תשלומי Stripe בחנות (מסלול א׳).
4. הכנת קבצי PWA/TWA לפרסום בגוגל פליי + מדריך העלאה.

## פרטים טכניים

- Lovable Cloud (Supabase): auth עם Google provider, טבלת `profiles` עם RLS, פונקציית `has_role` לא נדרשת (אין אדמין בשלב זה). migration יכלול GRANTs מלאים.
- סנכרון: בעת התחברות — מיזוג localStorage ← ענן (לוקחים את הערך הגבוה/החדש); כל שינוי נשמר מקומית ונדחף לענן (debounce).
- דירוג: טבלת `leaderboard` (user_id, country, score, period) עם אינדקסים; חישוב ניקוד בצד שרת.
- תשלומים: Stripe Checkout דרך פונקציית שרת + webhook ב-`/api/public/stripe-webhook` עם אימות חתימה, שמזכה מטבעות/פרימיום בטבלה.
- TWA: `public/manifest.webmanifest` מלא, אייקונים, `/.well-known/assetlinks.json`, מדריך Bubblewrap.
- ללא Capacitor בשלב זה; גוגל פליי דורש חשבון משלך ו-Play Billing למכירות בתוך האפליקציה.
